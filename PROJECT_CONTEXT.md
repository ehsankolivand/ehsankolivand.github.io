## 1. Summary

This repo is a personal website for **Ehsan Kolivand** (Senior Android Engineer, Istanbul),
hosted on **GitHub Pages** at `https://ehsankolivand.github.io/`. It contains two things:
(1) a pre-existing, hand-maintained **portfolio** single page (`index.html`), and (2) an
**Obsidian-vault-driven static blog** generated by a small **Python** build tool. The author
writes one Markdown note per post (YAML frontmatter + Markdown body, optional related links at
the end) under `content/blog/`; a deterministic, dependency-light generator renders each note —
plus a blog index — into HTML templates that were extracted verbatim from a pre-designed blog
"bundle", producing **SEO-complete static HTML** (real content in the initial markup), a
regenerated `sitemap.xml`, and an auto-synced "Field notes" section on the portfolio homepage.
The whole site is assembled into `_site/` and deployed by GitHub Actions on push to `main`.
The portfolio page is copied **byte-for-byte** (except one managed region) and never edited by
the build. **[confirmed]** — `scripts/build_blog.py`, `specs/001-obsidian-blog/plan.md`,
`.specify/memory/constitution.md`, live build run.

A second feature, **`002-seo-geo-publish`** (best-in-class SEO + GEO with one-commit publishing),
has since been implemented on top of this: it unifies the blog's structured-data identity with the
portfolio (shared `#person`/`#website` `@id`), adds a build-generated **Atom feed** (`/blog/feed.xml`)
and a build-generated **`llms.txt`** post index, enriches per-page metadata (BreadcrumbList,
`og:image` dimensions+alt, `twitter:image:alt`, `wordCount`/`timeRequired`, a semantic `<time>`
date), and **eliminates the stale-homepage defect** by neutralizing the committed Field-notes region
to be post-link-free (the build still injects live cards). It is governed by **Constitution v1.2.0**
(now **8** principles — Principle VIII added). **[confirmed — implemented + verified this cycle]**

Current state: **working and verified**. A fresh build produces 3 posts and the verifier passes
**163 checks, 0 failures** (was 90 before feature 002). **[confirmed — ran the build]**

## 2. Purpose and goals

- **Problem solved**: publish blog posts to a zero-backend GitHub Pages site by writing a single
  Obsidian Markdown note and pushing — no CMS, no client-side rendering, no hand-edited HTML —
  while keeping the existing, deliberately-designed look and full SEO/GEO metadata. **[confirmed]**
  `specs/001-obsidian-blog/spec.md` Overview.
- **Defining constraint**: the site has no backend and must rank in search engines and be
  readable by AI assistants, so **every post's content and metadata must be present in the served
  static HTML before any script runs**. A prior page on this site reportedly failed because it was
  client-rendered; that failure mode is forbidden by construction. **[confirmed]**
  `.specify/memory/constitution.md` Principle I.
- **Governed by a constitution** (`.specify/memory/constitution.md`, **v1.2.0**, ratified
  2026-06-27, last amended 2026-06-29) with **8 NON-NEGOTIABLE principles**: (I) SEO-correct static
  generation, (II) GitHub Pages only / no backend, (III) design fidelity (reproduce the bundle, do
  not restyle), (IV) Obsidian as the single content source, (V) per-page SEO/GEO completeness, (VI)
  accessibility & Core Web Vitals, (VII) non-destructive to the existing portfolio, **(VIII)
  machine-readable discovery & single-source publishing** (added by feature 002: build-generated
  Atom feed + `llms.txt` listing every post, unified `@id` identity, one-commit publishing where
  every derived artifact regenerates deterministically, and no dangling committed links). **[confirmed]**
- **Authoring promise (SC-001)**: publish a post by editing/committing exactly one Markdown note
  (plus optional related links) — no other file edits. **[confirmed]** `spec.md`.

## 4. Architecture overview

Three concern boundaries (Structure Decision, `plan.md`): **author surface** (`content/blog/`),
**design** (`templates/blog/`, extracted once from the bundle), **generator** (`scripts/`). CI
assembles `_site/` and deploys it; `_site/` is a git-ignored build artifact. **[confirmed]**

### Execution path (a build run)

Entry point: **`scripts/build_blog.py:main()`**. Order of operations **[confirmed — read in full]**:

1. **Parse args** (`--out` default `_site`, `--base-url` default
   `https://ehsankolivand.github.io/`, `--drafts`).
2. **Safety guards**: refuse to build into the repo root / an ancestor; refuse to `rmtree` an
   `--out` that looks like a source dir (contains `.git/scripts/templates/content/specs`).
3. **Load + validate content** — `blog.content.load_categories()` then `load_posts()`. Fails loud
   on bad input (missing required frontmatter, unknown category, duplicate slug, unparseable date,
   missing image/alt). Posts sorted newest-first (`-date.toordinal()`, slug tiebreak). Related
   links resolved by slug then title.
4. **Fresh `_site/`** (rmtree + mkdir).
5. **Copy root companions verbatim** from `config.ROOT_COPY_ALLOWLIST` (portfolio `index.html`,
   `robots.txt`, `site.webmanifest`, favicons, `og-image.png`). Missing items in
   `config.ROOT_REQUIRED` abort the build. `.nojekyll` is always written (not copied). **Note (002):
   `llms.txt` is NO LONGER copied here — it is generated in step 12c.**
6. **Auto-sync homepage "Field notes"** — if `_site/index.html` has both `<!--LATEST-NOTES:START-->`
   / `<!--LATEST-NOTES:END-->` markers and posts exist, regenerate **only that region** with the
   latest 3 posts (`render.render_home_notes`). Repo source `index.html` is never written.
7. **Copy design assets** `templates/blog/assets/*` → `_site/blog/assets/` (css, js, fonts).
8. **Copy author media** `content/blog/assets/*` → `_site/blog/assets/media/`.
9. **Measure image covers** (PNG/JPEG/GIF intrinsic size via stdlib `image_size()`) for no-CLS.
10. **Render each post** → `render.render_article_page()` → `_site/blog/<slug>/index.html`.
11. **Render index** → `render.render_index_page()` → `_site/blog/index.html`.
12. **Regenerate sitemap** → `sitemap.build_sitemap()` → `_site/sitemap.xml`.
12b. **Generate Atom feed** (002) → `feed.build_feed()` → `_site/blog/feed.xml` (deterministic; one
   entry per post; feed `updated` = max post `updated`, or `PORTFOLIO_LASTMOD` when empty).
12c. **Generate `llms.txt`** (002) → `llms.build_llms(read(config.LLMS_SRC), posts, base_url)` →
   `_site/llms.txt` (committed identity base + appended `## Writing` post list; idempotent).
13. **Report** counts to stdout (now incl. feed entry count + llms.txt note).

Then CI runs **`scripts/verify_build.py`** (Definition-of-Done gate) and, if green, deploys.

## 5. Data model and key types

In-memory only (no persistence). Authoritative definitions: `content.py` dataclasses;
spec mirror in `specs/001-obsidian-blog/data-model.md`. **[confirmed both]**

### `Post` (one `content/blog/*.md` note → one page at `/blog/<slug>/`)

| Field | Frontmatter key | Type | Required | Default / derivation |
|---|---|---|---|---|
| title | `title` | str | **yes** | — (becomes the single `<h1>`) |
| date | `date` | date `YYYY-MM-DD` | **yes** | — (= `datePublished`) |
| updated | `updated` | date | no | = `date`; must be `>= date` (= `dateModified`) |
| category | `category` | str | **yes** | must be a `name` in `categories.yml` |
| tags | `tags` | str[] (or comma str) | no | `[]` → meta keywords + JSON-LD keywords + `article:tag` |
| excerpt | `excerpt` **or** `description` | str | **yes** | — (dek + meta description + OG/Twitter description) |
| slug | `slug` | str | no | `slugify(title)`; re-slugified if non-canonical; **unique (collision = error)** |
| cover | `cover` | Cover | no | code cover, glyph `{ }`, caption `// <cat> · <slug>` |
| read_time | `readTime` | str | no | computed `ceil(words/220) min` |
| canonical | `canonical` | URL | no | `<base>/blog/<slug>/` |
| og_description | `ogDescription` / `socialDescription` | str | no | = excerpt |
| image | `image` (or `cover.src`) | path | no | "" → OG/JSON-LD fall back to `/og-image.png` |
| draft | `draft` | bool | no | `false` (true ⇒ excluded from index/pages/sitemap unless `--drafts`) |
| body | (markdown after frontmatter) | markdown | **yes** | non-empty after related-block strip |
| related_slugs / related | end-of-body links | str[] / Post[] | no | resolved at build; unresolved ⇒ warning |

`@property url` = `/blog/<slug>/`; `display_date()` = e.g. `Jun 28, 2026`. **[confirmed]**

### `Cover` sub-model

`kind`: `"code"` (default) | `"image"`. Code cover: `glyph`, `caption`. Image cover: `src`
(under `content/blog/assets/`, copied to `/blog/assets/media/`), `alt` (**required** for images),
`width`/`height` (default 1200×630, overwritten by measured intrinsic size for PNG/JPEG/GIF).
Shorthand: bare string with `/` or image extension ⇒ image cover; else ⇒ code glyph. **[confirmed]**

### `Category` (declared in `content/blog/categories.yml`, ordered)

`name` (unique, the key posts reference), `label` (default = name), `palette`
(`mint`|`sand`; default mint for `Tooling`/`Compose`, sand otherwise; other value = error).
Order in file = nav order after the always-present "All". Current set: **Compose, Architecture,
Tooling, Crypto**. **[confirmed]** `categories.yml`.

### Validation (build fails loud — `ContentError`)

Required frontmatter present; `category` ∈ categories; `slug` unique; dates parse and
`updated >= date`; image cover `src` resolves and has `alt`; body non-empty; related links resolve
(else warning). Verifier additionally asserts exactly one `<h1>` and no unresolved template tokens.
**[confirmed]** `content.py`, `verify_build.py`.

## 10. Conventions in use

- **Spec-driven development (Spec Kit)**: work flows constitution → specify → clarify → plan →
  tasks → analyze → checklist → implement. Every artifact must pass the Constitution Check; a
  principle is never weakened to silence an error ("no silent degradation"). **[confirmed]**
  constitution Governance + `plan.md` Constitution Check (all 7 PASS).
- **Determinism is mandatory**: same content in → byte-identical HTML out (no `today()`, stable
  sort order, single-pass token substitution). **[confirmed]** `sitemap.py`, `content.py`.
- **Fail loud, never silent**: invalid input aborts the build with a file-identifying message;
  unresolved related links warn but don't fail. **[confirmed]** `content.py`.
- **Security-by-construction in the renderer**: HTML escaping everywhere; URL scheme allow-list
  (`http/https/mailto`/relative) neutralizes `javascript:`/`data:`; single-pass substitution blocks
  author-text token injection. **[confirmed]** `markdown_render.py`.
- **Naming**: kebab-case slugs/URLs; snake_case Python; `{{UPPER_SNAKE}}` template tokens;
  `data-*` hooks drive JS (no content rendering in JS). Module docstrings cite the principle/FR
  each enforces. **[confirmed].**
- **Branching/commits**: single active branch `main` (feature branch name `001-obsidian-blog` lives
  only as a spec folder). 14 commits, imperative subject lines, often prefixed by area
  ("Portfolio:", "Add post:", "Fix …"). Generated `_site/` and private material are git-ignored.
  **[confirmed]** `git log`, `.gitignore`.
- **Identity consistency (Principle V)**: one absolute URL and "Ehsan Kolivand / Senior Android
  Engineer / Istanbul" everywhere; the design bundle's placeholder "Koolivand" is corrected to
  "Kolivand" as data. **[confirmed]** `config.py`, `spec.md` Assumptions.

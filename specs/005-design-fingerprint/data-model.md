# Design "Data Model" — Entities of the Redesign

This feature has no runtime data model. The design entities below are the things the plan/tasks/verifier reason over.

## Entity: Fingerprint Token Layer
- **Fields**: colour tokens, type tokens, spacing tokens, motion tokens (see [contracts/fingerprint-token-layer.md](./contracts/fingerprint-token-layer.md)).
- **Invariants**: only existing palette hexes named; identical names/values on both surfaces; no new `@font-face`; contrast ≥4.5:1 for text.
- **Relationships**: consumed by every fingerprint class on both surfaces; is the concrete proof of FR-003 (one shared fingerprint).

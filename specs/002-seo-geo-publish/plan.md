# Implementation Plan: Best-in-Class SEO + GEO with One-Commit Publishing

**Branch**: `002-seo-geo-publish` | **Date**: 2026-06-29 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/002-seo-geo-publish/spec.md`

## Summary

Take the already-SEO-complete static blog to *best-in-class* for search engines and AI/generative
engines, and close the publishing-automation gap so adding/changing a post is a single commit whose
every derived artifact regenerates correctly. The work is an audit-and-complete pass on the existing
deterministic Python generator plus a few new **build-time, static** machine-readable surfaces — no
backend, no client rendering, no new runtime dependency, no restyle, and no edit to the portfolio
outside its one managed region.

Technical approach (all build-time, deterministic):
1. **Fix the live defect + lock it shut**: neutralize the committed portfolio homepage "Field
   notes" region to a post-link-free fallback (heading + dek + a single `/blog/` link). The build
   still regenerates the full region for deploy; the committed source can never again hold a
   dangling `/blog/<slug>/` link. A new verifier assertion enforces "no committed source links to a
   nonexistent post," permanently.
2. **Structured-data upgrade** (`scripts/blog/seo.py`): unify identity by referencing the
   portfolio's canonical `Person` (`…/#person`) and `WebSite` (`…/#website`) by `@id` and adding
   `sameAs`; add a `BreadcrumbList` to posts and the index; enrich `BlogPosting` (`url`,
   `wordCount`, `timeRequired`, `isPartOf` the `Blog`, `inLanguage`, `mainEntityOfPage`); add
   `og:image:width/height/alt` and `twitter:image:alt`. Omit `SearchAction` (no search endpoint)
   and Twitter handle attribution (no public handle) — honesty over fabricated capability.
3. **New GEO surfaces**: a new `scripts/blog/feed.py` emits a deterministic **Atom 1.0** feed at
   `/blog/feed.xml`; a new `scripts/blog/llms.py` reads the committed `llms.txt` (human-authored
   identity base) and appends a deterministic `## Writing` post list, writing the merged file to
   `_site/llms.txt`. Both pages and the feed are linked via `<link rel="alternate">` autodiscovery.
4. **Semantics/CWV**: wrap the post publish date in a `<time datetime>` element (zero visual
   change); keep intrinsic image dimensions and font preloads. Accessibility preserved.
5. **Verifier expansion** (`scripts/verify_build.py`): assert every new invariant (breadcrumb,
   unified `@id`, og/twitter image metadata, feed well-formed + complete, `llms.txt` complete,
   canonical + lastmod correctness, no dangling committed links). Coverage grows from 90 checks.

## Technical Context

**Language/Version**: Python 3.11+ (CI pins 3.12.7); local 3.12.7.

**Primary Dependencies**: `PyYAML==6.0.1` only. New code is stdlib-only (string building for Atom
XML, `html`, `json`, `datetime`, `re`, `math`). No Markdown library, no feed library — consistent
with the existing in-house posture.

**Storage**: Filesystem only. Source in `content/blog/`; generated site in `_site/` (git-ignored).

**Testing**: `scripts/verify_build.py` (post-build Definition-of-Done verifier). Baseline: 90
checks, 0 failures. This feature expands it; the optional addition of isolated renderer/feed unit
tests is out of scope (recorded in research.md).

**Target Platform**: Static web on GitHub Pages; must be fully readable by non-JS crawlers and AI
assistants.

**Project Type**: Static site generator (single project: generator + templates + content).

**Performance Goals**: Build stays a few seconds. CWV preserved: CSS + 2 preloaded self-hosted
fonts are the only render-affecting resources; JS deferred and content-free; covers carry intrinsic
dimensions (no CLS); animations compositor-only, gated on `prefers-reduced-motion`.

**Constraints**: No backend/DB/server/paid service; deterministic (no `today()`); design reproduced
exactly (the only template edit is a semantic `<span>`→`<time>` swap with identical styling);
portfolio untouched outside its managed region; one absolute URL
(`https://ehsankolivand.github.io/`); identity = "Ehsan Kolivand", Senior Android Engineer,
Istanbul.

**Scale/Scope**: Personal blog, 3 posts today, architecture scales to hundreds unchanged.

### Notes on two deliberate scope exclusions (honesty over fabricated signal — Principle V, FR-018)

- **No `SearchAction`**: a sitelinks search box requires a working search-results endpoint, which a
  no-backend static site cannot provide. A `SearchAction` pointing at a non-functional URL is a
  structured-data defect, not a benefit. Excluded by design.
- **No `twitter:site`/`twitter:creator`**: the author has no public X/Twitter handle on record
  (known profiles: GitHub, LinkedIn, Telegram — already in the portfolio `Person.sameAs`).
  Fabricating a handle would be wrong; the `summary_large_image` card is kept.

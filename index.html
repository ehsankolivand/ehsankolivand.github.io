Consulting for Radib — where my Android career started — building the agentic engineering platform behind its client app work: a pinned Kotlin Multiplatform base, deterministic code generation, and a repository-intelligence layer that lets a small team ship production-grade apps fast without spending the architecture budget to do it.

  • Own the shared KMP base — Compose Multiplatform, MVI, Decompose, multi-module Clean Architecture — where naming, placement and registration are formulas, so new features are generated deterministically instead of guessed by a model.
  • Build the enforcement ladder that keeps AI-written code honest: module graph, architecture tests, static analysis and agent-time hooks all resolve to one green gate, so delivery speed never comes out of the architecture.
  • Currently building a repository-intelligence layer for KMP codebases consumed by coding agents — module-topology discovery, compiler-grade symbol resolution, and a verified evaluation set with a measured token baseline, so the gains are proven rather than asserted.
